# Redesign Website PT ASDP Indonesia Ferry (Persero)

Proyek ini merupakan perancangan ulang (*redesign*) tampilan antarmuka website profil dan layanan **PT ASDP Indonesia Ferry (Persero)** berbasis web statis interaktif. Proyek ini disusun untuk memenuhi tugas **Ujian Tengah Semester (UTS)** mata kuliah Pemrograman Web dengan menerapkan standar desain modern, responsif (*desktop* & *mobile*), serta konvensi penamaan `id` dan `class` khusus.

## Ketentuan Teknis yang Diterapkan

1. **Jumlah Halaman (8 Halaman):** Melampaui batas minimal 7 halaman, mencakup halaman wajib `index.html` (Beranda) dan `kontak.html` (Formulir Pengiriman Pesan).
2. **Konvensi Penamaan CSS:** Seluruh selektor `id` dan `class` di seluruh file HTML, CSS, dan JavaScript menggunakan awalan nama mahasiswa (`rayival_`), seperti `#rayival_header`, `.rayival_nav_link`, `#rayival_hero`, dan `.rayival_card`.
3. **Teknologi Murni:** Dibangun menggunakan **HTML5, CSS3, dan Vanilla JavaScript** tanpa framework atau template eksternal.
4. **Desain Responsif:** Mendukung tampilan layar *desktop*, tablet, hingga perangkat *mobile* dengan menu navigasi adaptif (*hamburger menu*).
